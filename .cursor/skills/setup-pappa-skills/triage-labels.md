# Triage labels

Planning skills use one label when publishing agent-ready work: `ready-for-agent`. A full triage skill (if you add one later) uses all five roles.

| Role | Label in this repo | Meaning |
|------|-------------------|---------|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate |
| `needs-info` | `needs-info` | Waiting on reporter |
| `ready-for-agent` | `ready-for-agent` | Specified enough for an AFK agent |
| `ready-for-human` | `ready-for-human` | Needs human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill says "apply the ready-for-agent label", use the string from the **Label in this repo** column.

Edit the second column to match your tracker's vocabulary.
