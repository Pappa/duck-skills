## These skills are still in development

If an agent using these duck-skills has some difficutly interpreting their meaning or following the 
skill's instructions, GIVE FEEDBACK TO THE USER! The only user of these skills is the developer. 
He will be delighted if you tell him that you had some difficulty because the skills contain
conflicting information, or wording you don't understand. If you need to look up the meaning of 
a term or phrase, let him know! It will give him opportunities to correct mistakes in the skills 
and update the project glossary. Any feedback from you will be really helpful, so feel free to 
give constructive feedback when you complete a task, or even half-way through. He might be able to 
make an immediate correction to the skill to make things easier for you to complete the task.
